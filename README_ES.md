## ✨ Características Principales

1. **Control Totalmente Sigiloso (Zero-Trace Stealth Engine)**:
   - Control por códigos secretos de 3 dígitos (`777`, `000`, `666`, `444`, `555`, `999`).
   - Los mensajes de comando se **eliminan físicamente al instante** tras su envío. Ningún miembro del grupo se percatará de su presencia.
   - Normalización de números persas/árabes (`۰۰۰`, `۷۷۷`) y espacios adicionales.

2. **Dos Modos de IA**:
   - **👥 Modo Compañero / Piloto Automático (Pal Mode - `777`)**: Toma el control de conversaciones o grupos específicos interpretando la personalidad elegida.
   - **💼 Asistente Personal Universal (Assistant - `666`)**: Atiende de forma educada y profesional todos los chats privados (DMs) las 24 horas del día.

3. **🕵️ Interacción Automática en Grupos (Auto-Engage / Lurker - `777 engage`)**:
   - La IA observa el grupo y, a intervalos inteligentes de N minutos, analiza la charla e interviene de manera natural cuando surge un tema propicio.

4. **⚡ Simulación Humana de Escritura y Lectura**:
   - Tiempos de lectura proporcionales a la longitud del mensaje y velocidad realista de tecleo con estado continuo de `escribiendo...`.

5. **🧠 Memoria Dual (Corto y Largo Plazo)**:
   - Contexto preciso de los últimos 30 mensajes con resúmenes periódicos en segundo plano de detalles importantes del contacto.

6. **🧹 Purga Fantasma 999 (Ghost Purge)**:
   - Elimina en segundos y sin dejar rastro todo tu historial de mensajes en la conversación actual.

## 🎮 Matriz de Códigos Secretos (Comandos)

> 💡 **Todos los comandos se autodestruyen de inmediato** y solo pueden ser ejecutados por el dueño de la cuenta.

| Comando | Alcance | Acción y Efecto |
| :--- | :---: | :--- |
| `777` | Chat actual | **Activa el Modo Compañero** (personalidad por defecto). |
| `777 <personalidad>`| Chat actual | **Activa una personalidad específica** (ej: `777 sarcastic` o `777 academic`). |
| `777 engage [min]` | Chat actual | **Activa la participación periódica** (por defecto cada 20 min). |
| `777 engage off` | Chat actual | **Desactiva la participación automática** en este chat. |
| `777 engage off all`| Global | **Desactiva la participación automática en todos los chats**. |
| `000` | Chat actual | **Apaga el Modo Compañero** en esta conversación. |
| `000 all` | Global | **Apaga el Modo Compañero en todos los chats**. |
| `666` | Todos los DMs | **Activa el Asistente Personal** para todos los mensajes privados. |
| `444` | Chat actual | **Pausa el Asistente** solo para este contacto privado. |
| `444 all` | Todos los DMs | **Desactiva el Asistente Personal globalmente**. |
| `111 <instrucción>` | Chat / Respuesta | **Respuesta puntual inteligente** según tu instrucción específica. |
| `808` | Respuesta | **Voz a texto (STT)**: Transcribe mensajes de voz o videos a texto. |
| `809` | Chat / Respuesta | **Voz inteligente**: Genera una respuesta de voz inteligente usando IA. |
| `810` | Chat actual | **Ajustes de voz**: Lista 30 voces diferentes para seleccionar tu favorita. |
| `555` | Chat actual | **Panel de Estado** (informe breve que se borra en 4s). |
| `333` | Chat actual | **Reinicia la memoria a corto plazo** de este chat. |
| `999 [límite]` | Chat actual | **Ghost Purge** (elimina tus mensajes, escanea hasta 3000). |
| `998 [límite]` | Chat actual | **Smart Ghost Purge** (más rápido, solo busca tus mensajes). |
| `888` | Chat actual | **Muestra el menú de ayuda**. |

## 🎭 Modos Duales de IA y Motor de Personalidades

GhostGram incluye más de 13 personalidades listas para usar en la carpeta `personas/`:

- `normal.txt`: Amistoso, coloquial y cercano.
- `academic.txt`: Intelectual, riguroso y con citas formales.
- `sarcastic.txt`: Ingenioso, irónico y mordaz.
- `angry.txt`: Impaciente y directo pero con argumentos claros.
- `poetic.txt`: Elegante, reflexivo y poético.
- `assistant.txt`: Educado, resolutivo y formal para asuntos profesionales.

> **✨ Crea tu propia personalidad:** Solo añade un archivo `.txt` en la carpeta `personas/` (ej: `gamer.txt`) y úsalo con `777 gamer`.

## 🚀 Inicio Rápido e Instalación

### 🌟 Opción 1: Ejecución en 1 Clic en Windows (Sin código ni VPS)
Si deseas usar GhostGram en tu computadora Windows fácilmente:

1. Descarga o clona este repositorio.
2. Haz doble clic en **`run.bat`**.
3. En la primera ejecución, el script verificará Python, instalará las dependencias necesarias y abrirá un asistente interactivo para ingresar tus claves y biografía.
4. **¡Listo!** En el futuro, solo vuelve a hacer doble clic en **`run.bat`** cuando quieras activar tu bot.

---

### 💻 Opción 2: Instalación Local por Terminal (CLI)

```bash
# 1. Clonar el repositorio
git clone https://github.com/faithsaly5-stack/GhostGram.git
cd GhostGram

# 2. Crear y activar entorno virtual
python -m venv venv
# En Windows:
venv\Scripts\activate
# En Linux / macOS:
source venv/bin/activate

# 3. Instalar librerías
pip install -r requirements.txt

# 4. Configurar variables (.env)
python setup.py

# 5. Iniciar sesión en Telegram
python login.py

# 6. Iniciar GhostGram
python main.py
```

### ☁️ Opción 3: Despliegue Gratuito 24/7 en la Nube (Railway / Render - Sin VPS)
Puedes alojar GhostGram de forma 100% gratuita las 24 horas del día en plataformas en la nube:

#### 🔑 Paso 1: Generar la Cadena de Sesión (SESSION_STRING)
Dado que los servidores en la nube no disponen de terminal interactivo para solicitar el código de SMS:
1. Ejecuta `python login.py` (o haz doble clic en `run.bat`) en tu computadora.
2. Inicia sesión con tu número de teléfono y código de Telegram.
3. El script imprimirá una cadena de texto larga **`SESSION_STRING`** (comienza por `1Ap...`). Cópiala.

---

#### 🚀 Paso 2: Desplegar en [Railway.app](https://railway.app) (Recomendado)
1. Haz un Fork de este repositorio en tu cuenta de GitHub.
2. Inicia sesión en Railway.app ➡️ Haz clic en **New Project** ➡️ **Deploy from GitHub repo** ➡️ Selecciona `GhostGram`.
3. En la pestaña **Variables** de tu servicio, añade las siguientes variables:
   - `API_ID`: Tu API ID de Telegram
   - `API_HASH`: Tu API Hash de Telegram
   - `PHONE_NUMBER`: Tu número de teléfono
   - `SESSION_STRING`: La cadena obtenida en el Paso 1
   - `GEMINI_API_KEYS`: Tu clave API de Google Gemini
   - `OWNER_ID`: Tu ID numérico de Telegram
   - `OWNER_NAME`: Tu nombre
   - `OWNER_BIO`: Tu profesión / biografía
4. Railway compilará automáticamente con el Dockerfile incluido y mantendrá tu bot activo 24/7.

---

#### 🚀 Paso 3: O Desplegar en [Render.com](https://render.com)
1. En Render.com, haz clic en **New +** ➡️ **Background Worker**.
2. Conecta tu repositorio de GitHub.
3. Elige el entorno **Docker** (o **Python 3** con Build: `pip install -r requirements.txt` y Start: `python main.py`).
4. En la pestaña **Environment Variables**, ingresa tus variables incluyendo `SESSION_STRING`.
5. Haz clic en **Deploy**.

---

### 🖥️ Opción 4: Despliegue en 1 Clic a Servidor Linux VPS (Systemd)
Si dispones de un servidor Linux VPS:

1. En tu archivo local `.env`, ingresa los datos de conexión SSH:
   ```env
   VPS_IP=your.vps.ip.here
   SSH_USER=root
   SSH_PORT=22
   ```
2. Haz doble clic en **`deploy.bat`** (en Windows) o ejecuta `./deploy.sh` (en Linux).
3. El script empaquetará el proyecto, lo subirá por SCP, creará el entorno virtual y habilitará el servicio persistente `ghostgram.service`.
