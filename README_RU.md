## ✨ Ключевые возможности

1. **Полная скрытность (Zero-Trace Stealth Engine)**:
   - Управление секретными 3-значными кодами (`777`, `000`, `666`, `444`, `555`, `999` и др.).
   - Сообщения с командами **мгновенно удаляются физически** сразу после отправки. Собеседники не видят никаких следов бота.
   - Поддержка нормализации арабских/персидских цифр (`۰۰۰`, `۷۷۷`) и пробелов.

2. **Два основных режима AI**:
   - **👥 Режим Автопилота / Друга (Pal Mode - `777`)**: Включается в конкретных чатах и группах для живого общения от вашего имени.
   - **💼 Универсальный Личный Ассистент (Assistant - `666`)**: Вежливый секретарь, круглосуточно отвечающий на входящие личные сообщения (DMs).

3. **🕵️ Автоматическое вовлечение в беседу (Auto-Engage / Lurker - `777 engage`)**:
   - AI следит за активностью в группе и каждые N минут оценивает контекст, чтобы естественно и органично поддержать тему разговора.

4. **⚡ Реалистичная симуляция человека (Human Simulator)**:
   - Расчет времени на прочтение сообщений + живая скорость печати с постоянным статусом `typing...`.

5. **🧠 Двухуровневая память (Dual-Tier Rolling Memory)**:
   - Точный контекст последних 30 сообщений + периодическая фоновая суммаризация ключевых фактов о собеседнике в долгосрочную память.

6. **🧹 Призрачная очистка 999 (Ghost Purge)**:
   - Быстрое и незаметное удаление всей вашей истории сообщений в текущем чате.

## 🎮 Секретная матрица команд (Коды управления)

> 💡 **Все команды отправляются вами в чат и моментально самоуничтожаются.**

| Команда | Область действия | Описание |
| :--- | :---: | :--- |
| `777` | Текущий чат | **Включить режим Друга/Автопилота** (стандартная персона). |
| `777 <персона>` | Текущий чат | **Включить определенную персону** (напр. `777 sarcastic` или `777 academic`). |
| `777 engage [мин]` | Текущий чат | **Включить авто-вовлечение** (периодическое участие в беседе, по умолчанию 20 мин). |
| `777 engage off` | Текущий чат | **Выключить авто-вовлечение** в этом чате. |
| `777 engage off all` | Все чаты | **Выключить авто-вовлечение глобально** во всех чатах. |
| `000` | Текущий чат | **Выключить режим Друга** в текущем чате. |
| `000 all` | Все чаты | **Выключить режим Друга во всех чатах**. |
| `666` | Все личные чаты | **Включить персонального ассистента** для всех личных сообщений (DMs). |
| `444` | Текущий чат | **Приостановить ассистента** только для текущего собеседника. |
| `444 all` | Все личные чаты | **Полностью отключить личного ассистента**. |
| `111 <текст/промпт>`| В чате / В ответ | **Разовый умный ответ от AI** по вашей инструкции. |
| `555` | Текущий чат | **Панель статуса** (краткий отчет, удаляется через 4 сек). |
| `333` | Текущий чат | **Сбросить оперативную память** для этого чата. |
| `999 [лимит]` | Текущий чат | **Ghost Purge** (удалить N своих сообщений, сканируя до 3000). |
| `998 [лимит]` | Текущий чат | **Smart Ghost Purge** (быстрее, поиск только ваших сообщений). |
| `888` | Текущий чат | **Показать справку по командам**. |

## 🎭 Двойной режим работы AI и движок персон

В комплекте GhostGram поставляется 13+ готовых характеров в папке `personas/`:

- `normal.txt`: Дружелюбный, естественный и живой собеседник.
- `academic.txt`: Эрудированный ученый с профессиональной терминологией.
- `sarcastic.txt`: Остроумный, саркастичный и ироничный друг.
- `angry.txt`: Вспыльчивый, дерзкий, но логичный характер.
- `poetic.txt`: Утонченный поэт и литератор.
- `assistant.txt`: Вежливый, деловой и пунктуальный личный секретарь.

> **✨ Добавление своего персонажа:** Просто создайте `.txt` файл в папке `personas/` (например, `streamer.txt`) и активируйте его командой `777 streamer`!

## 🚀 Быстрый старт и варианты установки

### 🌟 Вариант 1: Запуск в 1 клик на Windows (Без кода и VPS)
Если вы хотите просто запустить бота на своем ПК:

1. Скачайте или клонируйте проект.
2. Дважды кликните по файлу **`run.bat`**.
3. При первом запуске скрипт автоматически проверит Python, установит библиотеки и запустит интерактивный мастер настройки для ввода API ключей и био.
4. **Готово!** В дальнейшем для запуска бота просто кликайте по **`run.bat`**.

---

### 💻 Вариант 2: Локальная установка через терминал (CLI)

```bash
# 1. Клонирование репозитория
git clone https://github.com/faithsaly5-stack/GhostGram.git
cd GhostGram

# 2. Создание и активация виртуального окружения
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

# 3. Установка библиотек
pip install -r requirements.txt

# 4. Настройка конфигурации (.env)
python setup.py

# 5. Авторизация в Telegram
python login.py

# 6. Запуск GhostGram
python main.py
```

### ☁️ Вариант 3: Бесплатный хостинг 24/7 в облаке (Railway / Render - Без VPS)
Вы можете запустить GhostGram бесплатно 24/7 в облаке без необходимости держать включенным свой компьютер:

#### 🔑 Шаг 1: Получение ключа сессии (SESSION_STRING)
Поскольку облачные серверы работают без интерактивного терминала и не могут запросить SMS-код:
1. Запустите `python login.py` (или дважды кликните `run.bat`) на своем компьютере.
2. Войдите в Telegram с кодом подтверждения.
3. Программа сгенерирует и напечатает длинную строку **`SESSION_STRING`** (начинается с `1Ap...`). Скопируйте её.

---

#### 🚀 Шаг 2: Деплой на [Railway.app](https://railway.app) (Рекомендуется)
1. Сделайте Fork этого репозитория на свой GitHub.
2. Авторизуйтесь на Railway.app ➡️ **New Project** ➡️ **Deploy from GitHub repo** ➡️ выберите `GhostGram`.
3. Во вкладке **Variables** добавьте параметры:
   - `API_ID`: Ваш Telegram API ID
   - `API_HASH`: Ваш Telegram API Hash
   - `PHONE_NUMBER`: Ваш номер телефона
   - `SESSION_STRING`: Скопированная строка сессии из Шага 1
   - `GEMINI_API_KEYS`: Ключ API Google Gemini
   - `OWNER_ID`: Ваш Telegram ID (числовой)
   - `OWNER_NAME`: Ваше имя
   - `OWNER_BIO`: Ваша профессия / Биография
4. Railway автоматически соберет проект и запустит бота 24/7!

---

#### 🚀 Шаг 3: Или деплой на [Render.com](https://render.com)
1. В Render.com нажмите **New +** ➡️ **Background Worker**.
2. Подключите ваш GitHub репозиторий.
3. Выберите среду **Docker** (или **Python 3** с Build: `pip install -r requirements.txt` и Start: `python main.py`).
4. Во вкладке **Environment Variables** вставьте ваши переменные, включая `SESSION_STRING`.
5. Нажмите **Deploy**!

---

### 🖥️ Вариант 4: Автоматический деплой на Linux VPS (Systemd)
Если у вас есть собственный VPS-сервер:

1. В локальном файле `.env` укажите данные SSH:
   ```env
   VPS_IP=your.vps.ip.here
   SSH_USER=root
   SSH_PORT=22
   ```
2. Дважды кликните **`deploy.bat`** (или выполните `./deploy.sh` в Linux).
3. Скрипт сам упакует проект, загрузит по SCP, настроит окружение и создаст автозагружаемую службу `ghostgram.service`.
